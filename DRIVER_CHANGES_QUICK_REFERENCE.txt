┌─ TOP 5 MISTAKES TO AVOID ─────────────────────────────────────────────────────┐
│                                                                               │
│  ❌ #1: Calling motor_driver_init() in vehicle_system_run()                 │
│         → Causes "already initialized" conflicts when task starts            │
│         → FIX: Call inside motion_control_task() at startup instead         │
│                                                                               │
│  ❌ #2: Using sleep_ms() in task loops                                      │
│         → Blocks entire RTOS scheduler                                       │
│         → FIX: Use tk_dly_tsk(milliseconds) instead                         │
│                                                                               │
│  ❌ #3: Not protecting motor state with mutex                               │
│         → Race condition if multiple tasks call motor_set_speed()           │
│         → FIX: Add tk_loc_mtx() / tk_unl_mtx() around shared state         │
│                                                                               │
│  ❌ #4: Keeping multicore_launch_core1() calls                              │
│         → Conflicts with RTOS task scheduler                                │
│         → FIX: Remove from boot code, use task priorities instead           │
│                                                                               │
│  ❌ #5: Assuming I2C is not thread-safe                                     │
│         → Pico SDK I2C timeouts ARE safe; no mutex needed                   │
│         → ✅ OK: Multiple tasks can query sensors (they block safely)       │
│                                                                               │
